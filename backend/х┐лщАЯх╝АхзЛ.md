# ⚡ 快速开始 - 5分钟部署教学平台后端

> **适合人群**: 新手用户  
> **预计时间**: 5-10分钟  
> **前提条件**: 已安装宝塔面板

---

## 🚀 第一步：准备工作（1分钟）

### 1. 检查服务器环境

登录宝塔面板，确认已安装：
- ✅ MySQL 8.0
- ✅ Node.js 18.x
- ✅ PM2

**如果未安装，在宝塔【软件商店】安装上述软件**

---

## 📦 第二步：上传代码（2分钟）

### 方法1：压缩上传（推荐）

1. 在本地，将整个 `backend` 文件夹压缩成 `backend.zip`
2. 宝塔面板 → 【文件】→ `/www/wwwroot/`
3. 上传 `backend.zip`
4. 右键解压，重命名为 `teaching-platform-backend`

### 方法2：SSH命令

```bash
cd /www/wwwroot/
# 如果你已经有Git仓库
git clone <你的仓库地址> teaching-platform-backend

# 或者使用SCP上传
```

---

## 🗄️ 第三步：创建数据库（2分钟）

### 在宝塔面板操作

1. **创建数据库**
   - 宝塔 → 【数据库】→ 【添加数据库】
   - 数据库名: `teaching_platform`
   - 用户名: `teaching_user`
   - 密码: 自动生成（**复制保存！**）

2. **导入SQL**
   - 点击数据库【管理】→ 进入phpMyAdmin
   - 点击【SQL】标签
   - 复制 `backend/database/schema.sql` 内容，粘贴执行
   - 复制 `backend/database/init-data.sql` 内容，粘贴执行

**✅ 看到绿色提示 = 成功！**

---

## ⚙️ 第四步：配置环境（1分钟）

### 编辑.env文件

1. 宝塔 → 【文件】→ `/www/wwwroot/teaching-platform-backend/`
2. 重命名 `.env.example` 为 `.env`
3. 点击【编辑】，修改以下2行：

```bash
DB_PASSWORD=你刚才创建数据库的密码  ⬅️ 修改这里！
JWT_SECRET=aB3dE5fG7hJ9kL2mN4pQ6rS8tU0vW1xY  ⬅️ 修改为任意随机字符串
```

4. 保存

---

## 🚀 第五步：启动服务（1分钟）

### SSH终端执行

```bash
# 进入项目目录
cd /www/wwwroot/teaching-platform-backend

# 安装依赖（需要1-2分钟）
npm install --production

# 启动服务
pm2 start ecosystem.config.js

# 保存配置（开机自启）
pm2 save

# 查看状态
pm2 status
```

**✅ 看到 `status: online` = 成功启动！**

---

## ✅ 验证部署成功

### 测试接口

在浏览器访问（替换为你的服务器IP）：
```
http://你的服务器IP:8081/health
```

**✅ 看到以下JSON = 部署成功！**
```json
{
  "status": "ok",
  "timestamp": "...",
  "uptime": 123.456,
  "environment": "production"
}
```

---

## 🌐 第六步：配置Nginx（可选，但推荐）

### 在宝塔面板操作

1. 宝塔 → 【网站】→ 选择您的站点 → 【设置】
2. 点击【配置文件】
3. 复制 `backend/nginx.conf.example` 的内容
4. 粘贴替换配置文件内容
5. **修改域名**（将 `codebona.cn` 改成你的域名）
6. 保存

### 重启Nginx

```bash
nginx -t        # 测试配置
nginx -s reload # 重启
```

**✅ 测试成功后，访问 `https://你的域名/health` 应该也能看到JSON**

## 🎉 完成！下一步做什么？

### 1. 测试登录

```bash
curl -X POST http://你的服务器IP:8081/sys/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

**✅ 返回包含token的JSON = 登录成功！**

### 2. 部署前端

1. 修改前端API地址为 `https://你的域名`
2. 打包前端: `npm run build`
3. 上传 `dist/` 到 `/www/wwwroot/teaching-platform/`
4. 访问 `https://你的域名`

### 3. 修改管理员密码

- 登录系统后，在个人设置中修改密码
- 默认密码: `admin123`

## ❓ 遇到问题？

### 问题1：后端启动失败

```bash
# 查看详细日志
pm2 logs teaching-backend

# 常见原因：
# - 数据库密码错误 → 检查.env
# - 端口被占用 → 修改.env的PORT
```

### 问题2：数据库连接失败

```bash
# 检查数据库是否创建成功
mysql -u teaching_user -p
# 输入密码，能进入 = 数据库正常
```

### 问题3：接口返回404

```bash
# 检查后端是否启动
pm2 status

# 检查端口是否监听
netstat -tunlp | grep 8081
```
