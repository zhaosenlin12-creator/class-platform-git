# 宝塔部署详细指南

> **适用对象**: 新手用户  
> **服务器配置**: 阿里云2核4GB + 宝塔v9.2  
> **域名**: codebona.cn  
> **预计时间**: 1-2小时

---

## 📋 部署前准备清单

### ✅ 必须完成项

- [ ] 阿里云服务器已安装宝塔面板
- [ ] 宝塔面板可以正常登录（默认端口8888）
- [ ] 域名已备案并解析到服务器IP
- [ ] SSH可以连接服务器

---

## 🚀 第一步：上传代码到服务器

### 方法1：使用宝塔面板上传（推荐新手）

1. **打开宝塔面板** → 【文件】→ 进入 `/www/wwwroot/`
2. **新建目录** `teaching-platform-backend`
3. **上传文件**：
   - 将本地 `backend` 文件夹下的所有文件压缩成 `backend.zip`
   - 在宝塔面板上传 `backend.zip`
   - 解压到 `/www/wwwroot/teaching-platform-backend/`

### 方法2：使用Git克隆（推荐）

```bash
# SSH连接服务器后执行
cd /www/wwwroot/
git clone <你的Git仓库地址> teaching-platform-backend
```

---

## 🗄️ 第二步：创建数据库

### 1. 在宝塔面板创建数据库

1. 打开宝塔面板 → 【数据库】
2. 点击【添加数据库】
3. 填写以下信息：
   - 数据库名: `teaching_platform`
   - 用户名: `teaching_user`
   - 密码: 自动生成（记下来！）
   - 访问权限: `本地服务器`
4. 点击【提交】

![创建数据库示例](https://via.placeholder.com/600x300.png?text=宝塔创建数据库截图)

### 2. 导入数据库表结构

1. 在【数据库】列表中，找到 `teaching_platform`
2. 点击【管理】进入phpMyAdmin
3. 点击【SQL】标签
4. 打开本地文件 `backend/database/schema.sql`，复制全部内容
5. 粘贴到SQL输入框，点击【执行】
6. 看到绿色提示 "SQL查询已成功执行" ✅

### 3. 导入初始数据

1. 同样在【SQL】标签中
2. 打开本地文件 `backend/database/init-data.sql`，复制全部内容
3. 粘贴并执行
4. 看到绿色提示 "SQL查询已成功执行" ✅

**✅ 验证数据导入成功**：
- 在左侧数据库列表中，应该能看到20多个表
- 点击 `sys_user` 表，应该能看到1条管理员记录（admin）

---

## ⚙️ 第三步：配置环境变量

### 1. 创建.env文件

1. 宝塔面板 → 【文件】→ `/www/wwwroot/teaching-platform-backend/`
2. 找到 `.env.example` 文件
3. 点击【重命名】→ 改成 `.env`
4. 点击【编辑】

### 2. 修改配置

```bash
# 数据库配置（重要！）
DB_HOST=localhost
DB_PORT=3306
DB_NAME=teaching_platform
DB_USER=teaching_user
DB_PASSWORD=你刚才创建数据库时的密码  ⬅️ 修改这里！

# JWT密钥（重要！修改为随机字符串）
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production  ⬅️ 修改这里！

# 服务器配置
NODE_ENV=production
PORT=8081
HOST=0.0.0.0

# CORS配置（允许前端访问）
CORS_ORIGIN=https://codebona.cn
CORS_CREDENTIALS=true

# 接口限流
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX_REQUESTS=100
```

**⚠️ 重要提示**：
- `DB_PASSWORD` 必须填写正确，否则无法连接数据库
- `JWT_SECRET` 建议修改为一个复杂的随机字符串（可以在线生成）

## 📦 第四步：安装依赖

### 1. 打开SSH终端

**方法A：宝塔面板终端**
1. 宝塔面板 → 【终端】
2. 直接在浏览器中打开终端

**方法B：本地SSH工具**
```bash
ssh root@你的服务器IP
```

### 2. 安装npm依赖

```bash
# 进入项目目录
cd /www/wwwroot/teaching-platform-backend

# 安装依赖（需要1-3分钟）
npm install --production

# 等待安装完成，看到以下提示表示成功
# added XXX packages in XXXs
```

**如果遇到错误**：
```bash
# 清理npm缓存重试
npm cache clean --force
npm install --production
```

## 🌐 第六步：配置Nginx反向代理

### 1. 打开Nginx配置

1. 宝塔面板 → 【网站】
2. 找到您的站点（codebona.cn）
3. 点击【设置】→ 【配置文件】

### 2. 替换配置

1. 打开本地文件 `backend/nginx.conf.example`
2. 复制全部内容
3. 粘贴到宝塔的配置文件框（完全覆盖原内容）
4. **修改域名**（如果不是codebona.cn）：
   - 搜索 `codebona.cn`，替换为你的域名
5. 点击【保存】

### 3. 重启Nginx

```bash
# 在SSH终端执行
nginx -t  # 测试配置是否正确
nginx -s reload  # 重启Nginx
```

**✅ 看到 "test is successful" 表示配置正确**

## 🔒 第七步：配置HTTPS（SSL证书）

### 1. 使用宝塔面板申请免费证书

1. 宝塔面板 → 【网站】→ 选择站点 → 【设置】
2. 点击【SSL】标签
3. 选择【Let's Encrypt】（免费证书）
4. 勾选 `codebona.cn` 和 `www.codebona.cn`
5. 输入邮箱地址
6. 点击【申请】

**⏳ 等待30秒-1分钟，提示申请成功**

### 2. 强制HTTPS

1. 在SSL页面
2. 勾选【强制HTTPS】
3. 点击【保存】

**✅ 现在访问 http://codebona.cn 会自动跳转到 https://codebona.cn**

## ❓ 常见问题排查

### 问题1：后端启动失败

**症状**: `pm2 status` 显示 `errored` 或 `stopped`

**排查**:
```bash
# 查看详细错误日志
pm2 logs teaching-backend --lines 50

# 常见原因：
# 1. 数据库密码错误 → 检查 .env 文件
# 2. 数据库未创建 → 重新执行第二步
# 3. 端口被占用 → netstat -tunlp | grep 8081
```

### 问题2：前端访问404

**原因**: Nginx配置问题

**解决**:
```bash
# 检查Nginx配置
nginx -t

# 查看Nginx错误日志
tail -f /www/wwwlogs/teaching-platform-error.log
```

### 问题3：API请求跨域错误

**原因**: CORS配置问题

**解决**:
1. 检查 `.env` 文件中的 `CORS_ORIGIN` 是否正确
2. 重启后端: `pm2 restart teaching-backend`

### 问题4：SSL证书申请失败

**原因**: 域名未正确解析

**解决**:
```bash
# 检查域名解析
ping codebona.cn

# 应该返回您的服务器IP
```
