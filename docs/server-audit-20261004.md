# 线上发布审计记录（2026-10-04）

本轮为非破坏性真实冒烟审计，不执行爆破、不写入业务数据、不使用生产账号提交登录。

## 已验证

- 首页：HTTP 200，Nginx 正常返回前端页面。

- 发布日志：Docker 镜像构建完成，`teaching-backend` 容器已启动；首次健康探测发生在容器刚启动时，随后重试成功，属于启动竞态而非持续故障。

## 注意事项

- 根页面本轮响应头中未观察到 `Strict-Transport-Security`；建议后续在 Nginx HTTPS server 块补充 HSTS，并先确认所有子域名均已 HTTPS。

## 发布结论

当前线上版本健康，前端首页、后端健康检查和验证码接口均可用；无需要立即回滚的现象。
