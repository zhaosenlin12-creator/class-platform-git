# 前端安全注意事项

## 已处理
- `socket.io-client` 升级至 `^4.7.5`，修复已知 `ws` 组件的 DoS 漏洞。
- `swiper` 升级至 `^5.4.5` 以满足 `vue-awesome-swiper` 的 peer 依赖要求。

## 待关注（暂无官方修复）
| 组件 | 漏洞描述 | 影响 | 建议措施 |
|------|----------|------|----------|
| `vue@2.x` / `vue-template-compiler` | 正则拒绝服务 / XSS 相关公告 | 中-高 | 后续计划升级至 Vue 3 或跟踪官方补丁；当前仅允许可信管理员操作模板。 |
| `vue-photo-preview@1.1.3` 依赖的旧版 `webpack-dev-server` | 开发环境路径遍历等漏洞 | 开发环境 | 仅在本地使用，生产构建不打包开发服务器；如需进一步降低风险，可寻找替代图片预览库。 |
| `meow@3.x` (`vue-photo-preview` 开发链路) | `trim-newlines` 无限循环 | 开发环境 | 仅在 CLI 工具调用时触发；保持关注后续补丁。 |

> 说明：上述组件仅在开发或构建环节使用，生产环境不直接暴露。上线前请再次执行 `npm audit`，并在有补丁时优先升级。
> 对应控制措施见《生产环境配置清单.md》安全项。
